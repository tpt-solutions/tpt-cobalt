# tpt-uir-ffi

[![CI](https://github.com/tpt-solutions/tpt-uir/actions/workflows/ci.yml/badge.svg)](https://github.com/tpt-solutions/tpt-uir/actions/workflows/ci.yml)
[![License: MIT OR Apache-2.0](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](#license)

C ABI (opaque-handle) bindings for inspecting **TPT-UIR** regions.

This crate exposes a read-only, C-callable API over a deserialized TPT-UIR
region. It is built as a `cdylib` / `staticlib` / `rlib` and a C header
(`include/tpt_uir_ffi.h`) is generated at build time with `cbindgen`.

## Installation

Not yet on crates.io. From Rust, depend on it via git or a path within this
workspace:

```toml
[dependencies]
tpt-uir-ffi = { git = "https://github.com/tpt-solutions/tpt-uir", package = "tpt-uir-ffi" }
```

From C/C++, build the `cdylib`/`staticlib` and link against the generated
header:

```sh
cargo build --release -p tpt-uir-ffi
# -> target/release/{libtpt_uir_ffi.so,tpt_uir_ffi.dll,libtpt_uir_ffi.a}
# -> crates/tpt-uir-ffi/include/tpt_uir_ffi.h (regenerated by build.rs via cbindgen)
```

## API

- `tpt_uir_load` — deserialize a postcard-encoded region into an opaque handle
- `tpt_uir_free` — release a handle
- `tpt_uir_block_count` / `tpt_uir_op_count` — counts
- `tpt_uir_op_dialect` / `tpt_uir_op_op` — op-name parts (borrowed pointers)
- `tpt_uir_op_operand(_count)` — operand access
- `tpt_uir_validate_ssa` / `tpt_uir_validate_dialect` — validation

### Example (C)

```c
#include "tpt_uir_ffi.h"
#include <stdio.h>

int main(void) {
    // `bytes` holds a postcard-encoded TPT-UIR region.
    void *handle = NULL;
    if (tpt_uir_load(bytes, bytes_len, &handle) != 0) return 1;

    size_t blocks = 0;
    tpt_uir_block_count(handle, &blocks);

    if (tpt_uir_validate_ssa(handle) != 0) {
        tpt_uir_free(handle);
        return 1;
    }

    tpt_uir_free(handle);
    return 0;
}
```
